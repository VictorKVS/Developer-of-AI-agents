# 02. Инвентаризация исходных материалов

Дата проверки: 2026-08-05

## Подтверждённое задание

Проект №01 соответствует **ДЗ 2235 PRO**: веб-приложение «редактор смыслов и тональности текста».

Обязательный результат:

1. Приём исходного текста.
2. Выбор цели коммуникации.
3. Выбор аудитории.
4. Выбор тональности.
5. Дополнительные параметры: формальность, длина, упрощение терминов.
6. Сохранение смыслового ядра исходного текста.
7. Три блока вывода: адаптированный текст, нейтральная версия, пояснение изменений.
8. Ссылка на приложение.
9. Скриншоты интерфейса.
10. Описание архитектуры промпта.
11. Описание самой сложной проблемы и способа её решения.

## Полученные учебные материалы

- инструкция по Google AI Studio;
- расширенное руководство по Google AI Studio и Gemini API;
- документ с формулировкой ДЗ 2235 PRO;
- пример технического задания «ИИ Путешественник».

Учебные руководства используются как reference-материалы курса и не являются исходным кодом проекта №01.

## Полученный исходный код

Загруженный React/Vite-комплект относится к приложению **«ИИ Путешественник»**, а не к редактору смыслов и тональности.

Поэтому он не размещается в `projects/01-text-meaning-tone-editor/` как реализация ДЗ 2235 PRO.

### Признаки другого проекта

- название приложения: «ИИ Путешественник»;
- входные параметры: направление, бюджет, поездка с детьми, настроение;
- результат: туристические направления и ссылки на источники;
- интерфейс построен вокруг подбора отпуска;
- типы данных описывают `TravelPreferences` и `TravelResult`.

## Технические замечания по комплекту «ИИ Путешественник»

1. В переданном комплекте отсутствуют импортируемые файлы:
   - `components/Background`;
   - `services/geminiService`.
2. Без этих файлов проект не является полным и не соберётся локально.
3. `vite.config.ts` подставляет `GEMINI_API_KEY` в клиентский bundle через `define`. Для публичного production-приложения это небезопасно: секрет должен использоваться на server-side.
4. `.env.local` не должен публиковаться; правило `*.local` в `.gitignore` присутствует.
5. README исходного экспорта содержит только базовый запуск и требует полноценного оформления.
