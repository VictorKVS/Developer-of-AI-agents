# 00. ДЗ 2235 PRO

## Задание

Разработать AI-приложение «редактор смыслов и тональности текста», которое адаптирует текст под цель коммуникации, аудиторию и контекст использования.

## Общая концепция

Пользователь вводит исходный текст и указывает:

- цель коммуникации;
- аудиторию;
- тон общения;
- при необходимости — уровень формальности, желаемую длину и допустимость упрощения терминов.

AI анализирует исходный текст и создаёт новую версию, адаптированную под заданные параметры, сохраняя исходный смысл.

Ключевая задача: изменить подачу и структуру без искажения содержания.

## Функциональные требования

### 1. Ввод данных

Обязательные поля:

- исходный текст;
- цель текста;
- аудитория;
- тональность.

Дополнительные параметры:

- контекст использования;
- уровень формальности;
- желаемая длина;
- допустимость упрощения терминов.

### 2. AI-обработка

AI должен:

1. проанализировать исходный текст;
2. выделить ключевой смысл;
3. переписать текст с учётом выбранных параметров;
4. сохранить смысловое ядро;
5. изменить структуру, стиль, подачу и уровень сложности.

### 3. Сравнение результатов

Пользователю должны быть доступны:

1. адаптированный текст;
2. оригинальный текст;
3. нейтральная версия.

### 4. Управление стилем и логикой

В промпте должны быть формализованы:

- цели;
- аудитории;
- тональности;
- описания параметров;
- примеры ожидаемого поведения текста.

### 5. Формат ответа

Ответ состоит из трёх блоков:

1. адаптированный текст;
2. нейтральная версия;
3. краткое объяснение изменений.

### 6. Интерфейс

Необходимы:

- поле ввода текста;
- выбор цели;
- выбор аудитории;
- выбор тона;
- дополнительные настройки;
- структурированное отображение результата;
- отображение оригинала для сравнения.

## Отчётность

В проекте должны быть представлены:

- ссылка на приложение;
- скриншоты интерфейса с примерами;
- архитектура промпта;
- описание самой сложной проблемы;
- описание способа её решения.

## Расширение проекта

В проекте принято дополнительное решение поддерживать до трёх циклов уточнения контекста. Перед уточнением пользователь получает предупреждение. После исчерпания лимита система формирует результат на основании имеющихся данных и явно указывает ограничения.
