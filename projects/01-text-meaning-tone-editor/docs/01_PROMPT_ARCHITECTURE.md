# 01. Архитектура промпта

## Цель

Промпт должен управлять трансформацией текста так, чтобы изменялись стиль, структура и уровень сложности, но сохранялось смысловое ядро.

## Слои промпта

### 1. Роль и задача

Модель получает роль редактора смыслов и тональности и инструкцию не добавлять факты, которых нет в исходном тексте.

### 2. Смысловое ядро

Перед переписыванием модель должна внутренне определить:

- главную мысль;
- ключевые факты;
- причинно-следственные связи;
- ограничения;
- обязательные формулировки, если они заданы.

### 3. Параметры трансформации

Передаются:

- цель коммуникации;
- аудитория;
- тональность;
- контекст использования;
- формальность;
- длина;
- допустимость упрощения терминов.

### 4. Правила аудитории

Для каждой аудитории задаётся ожидаемый уровень терминологии, глубины и объяснений.

Примеры:

- новичок — объяснять термины и избегать перегрузки;
- эксперт — сохранять профессиональную лексику;
- клиент — подчёркивать пользу и понятный результат;
- ребёнок — короткие фразы, простые примеры, без сложной терминологии.

### 5. Правила цели

Примеры:

- объяснить — логичная структура и причинно-следственные связи;
- убедить — аргументы и ясный вывод;
- продать — ценность, выгоды и призыв к действию;
- упростить — уменьшение сложности без потери ключевых фактов;
- предупредить — риски, последствия и необходимые действия.

### 6. Правила тональности

Тон влияет на лексику, ритм, обращение и эмоциональную интенсивность, но не должен менять факты.

### 7. Контракт вывода

Модель обязана вернуть:

```json
{
  "adapted_text": "string",
  "neutral_text": "string",
  "change_summary": ["string"],
  "meaning_preserved": true,
  "limitations": ["string"]
}
```

### 8. Самопроверка

Перед выдачей модель должна проверить:

- не добавлены ли новые факты;
- не удалены ли критически важные факты;
- соответствует ли текст цели;
- соответствует ли текст аудитории;
- соответствует ли текст тональности;
- соблюдён ли формат ответа.

## Цикл уточнения

Если данных недостаточно:

1. сообщить, что результат требует уточнения;
2. задать ограниченное число наиболее важных вопросов;
3. повторить цикл не более трёх раз;
4. после третьего цикла сформировать результат из доступных данных;
5. перечислить ограничения и допущения.

## Основной риск

Самая сложная проблема — смысловой дрейф: модель может сделать текст убедительнее или проще, одновременно добавив новые утверждения либо потеряв важные ограничения.

## Способ решения

- явное выделение смыслового ядра;
- запрет на добавление фактов;
- структурированный output;
- отдельная нейтральная версия;
- самопроверка сохранения смысла;
- тесты на фактическую эквивалентность;
- отображение оригинала рядом с результатом.
