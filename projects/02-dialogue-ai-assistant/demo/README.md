# Demo Data

Эта папка содержит только синтетические демонстрационные данные для MONGOOSE AI PLATFORM.

## Назначение

- демонстрация Professional Assessment;
- тестирование Dialogue Center;
- подготовка брендированных PDF;
- создание скриншотов для README;
- воспроизводимые сценарии без реальных персональных данных.

## Правила

- запрещено хранить реальные телефоны, email, адреса и документы;
- все совпадения с реальными людьми и организациями случайны;
- контакты используют безопасные демонстрационные значения;
- результаты AI не считаются окончательными кадровыми, психологическими или проверочными заключениями;
- все выводы требуют проверки человеком.
