# ДЗ 2236 PRO — чек-лист реализации

## Обязательные требования

- [ ] Рабочее веб-приложение, аналогичное показанному на встрече.
- [ ] Диалог пользователя с AI-моделью.
- [ ] Сохранение полной истории диалога.
- [ ] Завершение диалога отдельным действием пользователя.
- [ ] Вызов второй модели или отдельного аналитического промпта.
- [ ] Анализ всей истории диалога.
- [ ] Структурированная информация о пользователе.
- [ ] Итоговое резюме.
- [ ] Персональные рекомендации.
- [ ] Брендированный PDF-шаблон.
- [ ] Логотип в PDF.
- [ ] Дата формирования в PDF.
- [ ] Понятная структура отчёта.
- [ ] Кнопка или ссылка для скачивания PDF.

## Критерии качества

- [ ] PDF строится из результата аналитики, а не из механически собранных полей.
- [ ] Диалоговая и аналитическая модели разделены программно.
- [ ] Ответ второй модели проверяется строгой схемой.
- [ ] При нехватке данных это указывается в отчёте.
- [ ] У выводов есть показатель уверенности или явные ограничения.
- [ ] API-ключ отсутствует в репозитории.
- [ ] Повторное нажатие «Завершить» не создаёт дубликаты.
- [ ] Ошибки модели обрабатываются без потери истории.

## Демонстрационный сценарий

1. Запустить приложение.
2. Начать новый диалог.
3. Ответить минимум на 5 вопросов ассистента.
4. Завершить беседу.
5. Показать статус анализа.
6. Открыть итоговую аналитику.
7. Скачать PDF.
8. Продемонстрировать логотип, дату, резюме и рекомендации.
9. Показать в коде отдельные промпты диалога и анализа.
10. Показать `.env.example` без секретов.

## Definition of Done

Домашнее задание считается готовым, когда новый пользователь может клонировать проект, добавить собственный Gemini API key, выполнить инструкции запуска, провести диалог и скачать корректно оформленный PDF без ручного редактирования данных.
