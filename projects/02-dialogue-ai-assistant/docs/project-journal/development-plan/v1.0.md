# MONGOOSE AI PLATFORM — Development Plan v1.0

## 1. Цель

Построить универсальную платформу AI-агентов, развиваемую через последовательные учебные и практические проекты.

## 2. Главные правила

1. Один репозиторий — один продукт.
2. Каждый курс добавляет новый модуль или усиливает существующий.
3. Независимая логика размещается в `mongoose_core`.
4. Django отвечает за HTTP, ORM, Admin и интеграцию.
5. Каждая задача имеет номер `TASK-XXXX`.
6. Согласованные версии документов сохраняются отдельно и не перезаписываются без новой версии.

## 6. Definition of Done

Задача считается завершённой, когда:

- функциональность работает;
- результат проверен;
- добавлены необходимые тесты;
- документация обновлена;
- изменения отправлены в GitHub;
- журнал задач обновлён.
