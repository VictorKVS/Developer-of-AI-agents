# Project Journal

Этот каталог хранит согласованные этапы, версии документов и журнал разработки проекта MONGOOSE AI PLATFORM.

## Правила

1. Черновики сначала согласуются в рабочем диалоге.
2. После согласования документ получает номер версии и загружается в этот каталог.
3. Утверждённые версии не перезаписываются без новой версии.
4. Каждая значимая задача получает номер TASK-XXXX.
5. Архитектурные решения оформляются отдельно в `../adr/`.

## Структура

- `development-plan/` — план разработки и его версии.
- `tasks/` — карточки и журнал задач.
- `releases/` — итоги спринтов и релизов.
- `decisions/` — согласованные рабочие решения, не требующие отдельного ADR.
