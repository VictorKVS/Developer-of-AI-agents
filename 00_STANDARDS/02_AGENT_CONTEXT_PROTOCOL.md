# KVS Agent Context Protocol

## Назначение

Протокол определяет, как AI-агенты читают проект, используют накопленные знания и фиксируют новые решения.

## Обязательный порядок чтения

1. `project.manifest.yaml`
2. `00_ADMIN/03_PROJECT_JOURNAL.md`
3. `00_ADMIN/04_DECISIONS.md`
4. `04_DOCUMENTATION/01_CONCEPT.md`
5. `04_DOCUMENTATION/02_ARCHITECTURE.md`
6. `04_DOCUMENTATION/04_AGENT_MODEL.md`
7. `04_DOCUMENTATION/05_SECURITY.md`

## Правила работы агента

Агент обязан:

- сначала искать готовый компонент, сервис, промпт, схему или решение;
- учитывать принятые и отклонённые решения;
- не объявлять запланированную функцию реализованной;
- различать `demo`, `mock`, `implemented`, `tested` и `production-ready`;
- сохранять нумерованную структуру каталогов;
- не переносить секреты, реальные персональные и медицинские данные в публичный репозиторий;
- обновлять `project.manifest.yaml` после существенного изменения;
- добавлять запись в журнал проекта после завершённого этапа;
- создавать ADR при изменении архитектуры или границ модулей;
- прикладывать путь к файлу или тесту как доказательство реализации требования.

## Модель инженерной памяти

Проектная память разделяется на пять классов:

1. **Facts** — подтверждённые свойства текущей реализации.
2. **Decisions** — принятые и отклонённые архитектурные решения.
3. **Assets** — повторно используемые компоненты, сервисы, промпты и схемы.
4. **Constraints** — ограничения безопасности, курса, лицензий и технологий.
5. **Lessons** — ошибки, исправления и выводы из журнала проекта.

## Формат ссылки на повторно используемый актив

```yaml
- id: ui.modal.react.v1
  type: component
  source_project: 02-dialogue-ai-assistant
  path: projects/02-dialogue-ai-assistant/templates/...
  status: approved
  tags: [react, ui, modal]
  compatibility: [react-19]
  restrictions: []
```

## Формат решения

```yaml
- id: ADR-004
  status: accepted
  decision: Прогноз рассчитывается детерминированным модулем, а LLM только объясняет результат.
  reason: Требуется проверяемость и защита от выдуманных чисел.
  supersedes: null
```

## Формат записи этапа

```yaml
stage:
  id: STAGE-03
  date: 2026-08-05
  status: completed
  goal: Создать машиночитаемый стандарт инженерной памяти.
  changes:
    - 00_STANDARDS/00_KVS_ENGINEERING_STANDARD.yaml
    - 00_STANDARDS/01_PROJECT_MANIFEST.schema.json
  decisions:
    - Все проекты получают project.manifest.yaml.
  reusable_assets:
    - project_manifest_schema
  next_stage: Создать валидатор структуры и индекс знаний.
```

## Запреты

Агенту запрещено:

- удалять или перезаписывать журнал без явного решения;
- повторно предлагать решение со статусом `rejected`, не объяснив новые основания;
- считать мок-интеграцию реальным подключением;
- выдавать медицинскую рекомендацию как диагноз или лечение;
- смешивать исходные материалы курса с итоговым публичным продуктом;
- изменять структуру нумерации без ADR.
