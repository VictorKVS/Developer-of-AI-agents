# Developer of AI Agents

Учебный репозиторий курса **«Разработчик AI-агентов»**.

Здесь собираются практические проекты от простых диалоговых приложений до универсальной многоканальной платформы AI-агентов на Django.

## Главная цель

Создать повторно используемое ядро, на основе которого можно быстро разрабатывать новых специализированных агентов:

- консультантов;
- аналитиков;
- аудиторов;
- учебных помощников;
- агентов информационной безопасности;
- корпоративных ассистентов;
- агентов для Telegram, веб-сайтов, CRM и внешних API.

## Архитектурные принципы

- **API-first** — все функции доступны через версионируемый API.
- **Multi-channel** — веб, Telegram, email, CRM и другие каналы используют одно ядро.
- **Knowledge-first** — база знаний и RAG являются стандартной частью каждого агента.
- **Object-oriented** — интерфейсы, абстракции, наследование и композиция применяются осмысленно.
- **Reliable by design** — очереди, повторные попытки, идемпотентность, аудит и деградация без потери данных.
- **Evidence-based AI** — ответы сопровождаются источниками, оценкой уверенности и явными ограничениями.

## Текущий проект

### ДЗ 2236 PRO — Dialogue AI Assistant

Рабочее веб-приложение должно:

1. вести диалог с пользователем через AI-модель;
2. сохранять полную историю диалога;
3. после завершения беседы запускать отдельную аналитическую модель;
4. формировать структурированный профиль, резюме и рекомендации;
5. создавать брендированный PDF по шаблону;
6. предоставлять PDF для скачивания;
7. использовать архитектуру, пригодную для дальнейшего подключения API, базы знаний, каналов связи и новых агентов.

Подробное описание находится в [README проекта](./projects/02-dialogue-ai-assistant/README.md).

## Правила репозитория

- секреты и API-ключи не коммитятся;
- каждый проект располагается в отдельной папке;
- у каждого проекта есть README, `.env.example`, тесты и документация;
